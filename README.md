* **Mobile Warning:** This game is optimized for desktop computers. It may not run correctly or support touch controls on smartphones and tablets.
* **Stuck on a Blank Screen?** If the game fails to load, try hard-refreshing your browser (`Ctrl + F5` on Windows or `Cmd + Shift + R` on Mac) or open the link in an Incognito / Private window.
